# Full SF-SJ scenario

This is the frozen full-corridor baseline from San Francisco 4th & King to
San Jose Diridon along the Caltrain-referenced centerline.

- Corridor length: 75.423116 km
- Retained physical macro sites: BS01-BS18 (18 sites)
- Site inclusion rule: shortest planimetric distance to the full centerline no
  greater than 5 km
- Default flight: 300 m AGL, 50 m/s, zero lateral offset

The files in `data/` are byte-for-byte copies of the inputs used by the
published frozen reference. The legacy root-level `configs/` and `data/`
copies remain only so existing reference checks and external links do not
break.
