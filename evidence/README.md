# Corridor and site evidence

This folder contains the public, redistributable audit layer for the SF–SJ
scenario:

- `site_register.md`: one record per retained site with official and map links;
- `selection_method.md`: 5 km search band, physical-site and height rules;
- `site_classification.md`: macro-site classification convention;
- `excluded_sites.md`: documented exclusions, including former BS19;
- `figures/corridor_sites.*`: derived corridor/site map;
- `qa.json`: spatial and register consistency checks.

Third-party webpage screenshots and downloaded PDFs are intentionally excluded
from the public repository. Their source links remain available for audit.
